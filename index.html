StreamClipper

A personal tool that turns stream highlights into short vertical videos.

StreamClipper is a private, single-user desktop application run by the owner of the Devil Exxon channel. It finds highlight moments in livestream recordings from creators who have given permission to be clipped, edits them into short vertical videos with captions and a credit to the original creator, and posts them to the operator's own YouTube and TikTok accounts.

How it uses platform APIs

StreamClipper uses the YouTube Data API v3 only to upload and schedule videos on the operator's own YouTube channel. It uses the TikTok Content Posting API only to publish videos to the operator's own TikTok account. It does not access, collect or post to anyone else's account.
